# justintimetechnology.com (legacy, 2015)

**Superseded.** This is the 2015 PHP version of the Just-In-Time Technology Services site. The live site is built
and deployed from [justintimetech/justintimetechnology-website](https://github.com/justintimetech/justintimetechnology-website),
whose [docs/ci.md](https://github.com/justintimetech/justintimetechnology-website/blob/main/docs/ci.md) charts its
TeamCity pipelines.

TeamCity project `Justintimetechnologycom` still holds one placeholder build, `Build`, from this repository's
`.teamcity/settings.kts`: no steps, no trigger, no dependencies, never run. Nothing here deploys anywhere, so there
is no pipeline to chart.
